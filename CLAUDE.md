# marca-personal

Proyecto **no técnico** — plan estratégico de marca personal. No hay código, stack ni deploy.

## Dónde vive cada cosa (importante — evitar duplicación)
- **`README.md`** → fuente única de verdad: plan, narrativa, pendientes con checkboxes. Es repo público.
- **Memoria del proyecto** (`project_marca_personal.md`) → solo estado de alto nivel y decisiones recientes. NO duplicar pendientes aquí.

## Regla simple
- ¿Es una tarea pendiente? → README
- ¿Es parte del plan/estrategia? → README
- ¿Es un apunte de "lo que acabamos de decidir/hacer"? → memoria

Si algo aparece en ambos sitios, es bug: eliminar de la memoria y dejar solo en README.
